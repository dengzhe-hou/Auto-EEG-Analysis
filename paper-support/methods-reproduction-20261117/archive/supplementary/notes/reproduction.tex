\subsection*{Package entry points}
The review package supplies \path{unpack_review.py}, \path{REPRODUCTION.md}, \path{VERSION_MAP.csv} and \path{INPUT_MANIFEST.csv}. After extracting the assets into a new project directory, the documented Python entries are
\begin{quote}\small\ttfamily
python -B reproduction/replay\_current\_summary.py\\
python -B reproduction/check\_retained\_fields.py\\
python -B reproduction/check\_current\_outputs.py\\
python -B reproduction/recompute\_current\_references.py
\end{quote}
Each takes \texttt{--root} and \texttt{--output} arguments. Reference recomputation additionally takes \texttt{--input-root} with provider-input aliases. The accompanying \path{REPRODUCTION.md} gives complete commands and environment instructions. Summary replay uses NumPy 1.26.4. The current reference environment is Python 3.9, \mne{} 1.8.0, NumPy 1.26.4, SciPy 1.13.1 and Pillow. Paths in the reproduction instructions are supplied by the reader and do not require the author's home directory.

The current paired/model-cost material contains 900 assigned target sessions, comprising 600 Haiku sessions and 300 new Sonnet sessions. Its Haiku-plus-AEA comparator is reused for the Sonnet comparison. Exact frozen protocols and source snapshots govern the executed studies. Preparatory documents may retain an earlier pre-approval status and must not replace the final frozen protocol.

\subsection*{Provider access and archive status}
Raw EEG remains available under each original provider's terms. SEED-V signal fragments and private access links are not redistributed. Shared projections explicitly identify omitted arrays in \path{PUBLIC_EXCLUSIONS.json}, while the original deliveries remain retained by the author. Summary replay can use the non-signal aggregate records, but raw-data reproduction of restricted inputs requires the provider's authorization. Availability of an aggregate does not imply redistribution permission for the source signal.

The earlier Zenodo record 24012489 preserves its DOI and public metadata with files restricted pending correction. It does not contain the complete current validation package. Updated deposition remains a separate author-controlled step. The review package and the accompanying source-data index identify available materials and access conditions without claiming that a new public archive or DOI has already been issued.
