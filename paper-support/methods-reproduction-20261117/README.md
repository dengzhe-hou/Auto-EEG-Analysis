# Detailed methods and reproduction records

These materials accompany *Reusable skills for electroencephalography analysis with large language model agents*. The article contains the principal designs, endpoints, tolerances, statistical methods and interpretation. Its short Supplementary Information contains the ERP configuration table and a table distinguishing reproduction operations.

The [22-skill evidence table](skill-evidence.csv) gives each tested operation, reference, outcome and scope. It preserves the complete former Supplementary Table S1 without changing any entry.

The [balanced per-skill acceptance archive](../skill-acceptance-20261118/) records all 22 skills, both sets of first deliveries, the repair patch and a script to check the saved artifacts.

The [retained detailed PDF](archive/Supplementary_Information.pdf) and [editable source](archive/supplementary.tex) preserve the preceding eight-page supplement. Its original note and table numbers identify that archived document, rather than the current short supplement. The archived text records the same scientific methods and results. Reorganization does not change an analysis, score or tolerance.

Full first-delivery files, executed programs, protocol snapshots and detailed logs remain in the separately identified review and source-data packages. This directory contains explanatory records and evidence mappings. It does not claim to redistribute those entire packages or original EEG data.

The review package's `REPRODUCTION.md` gives complete commands with reader-supplied `--root`, `--output` and, for references, `--input-root` paths. Its entries are `reproduction/replay_current_summary.py`, `reproduction/check_retained_fields.py`, `reproduction/check_current_outputs.py` and `reproduction/recompute_current_references.py`. Summary replay, saved-output checking and new calculation from provider EEG are separate operations. None creates a new model session.

The earlier [analysis records](https://github.com/dengzhe-hou/Auto-EEG-Analysis/tree/6175cd2557c9f0332f2aa5344034a5310d8a0928/paper-support/analysis-details-20261109) and [extended records](https://github.com/dengzhe-hou/Auto-EEG-Analysis/tree/539d76d1f03fd88c8afb036c76aed0c6d053c7df/paper-support/extended-records-20261109) remain historical evidence archives. They do not substitute for a later study's exact frozen resources.

SEED-V signals and private access links are not included. Provider EEG remains subject to its original terms. The restricted earlier Zenodo record does not contain the complete current package. Updated deposition remains a separate author-approved step.
