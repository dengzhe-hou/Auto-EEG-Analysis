# Skill evidence records

The [operation-level evidence table](../../docs/SKILL_EVIDENCE.md) consolidates the retained records for all 22 AEA skills. The TSV and JSON files provide the same rows with tested operations, references, recorded outcomes and scope.

The compilation distinguishes the archived skill inventory from additional checks of selected operations. It preserves the original QC failure and the revised amplitude-helper checks. The original certification categories are unchanged. These files report existing evidence rather than newly executed numerical experiments.

The archived inventory and known-input checks are available in [Extended Records E09 and E10](https://github.com/dengzhe-hou/Auto-EEG-Analysis/blob/539d76d1f03fd88c8afb036c76aed0c6d053c7df/paper-support/extended-records-20261109/extended-supplement.pdf#page=11). The underlying known-input and QC JSON records are linked in each relevant row. Later matched MMN and five-component statistical comparisons are identified as manuscript evidence rather than attributed to the original inventory.
